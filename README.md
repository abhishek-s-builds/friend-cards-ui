👥 Friend Card UI

A simple and interactive Friend Card UI built using HTML, CSS, and JavaScript.

The project displays multiple user cards with profile images, names, and friendship status. Users can click the Add Friend button to change the status from Stranger to Friends, and click it again to remove the friend.

✨ Features

👤 Multiple user profile cards

➕ Add Friend functionality

❌ Remove Friend functionality

🔄 Dynamic friendship status

🎨 Status color changes

📱 Responsive layout

🖼️ Profile images using Unsplash

⚡ Built with vanilla JavaScript

🛠️ Technologies Used

HTML5 – Structure of the webpage

CSS3 – Styling and responsive layout

JavaScript – Interactive Add/Remove Friend functionality
